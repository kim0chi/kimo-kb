The working loop

Prompt in VS Code→Agent reads project context→Agent publishes to Kimo→You read and retain

Publish through a project-scoped bridge. A stable artifact key identifies each explanation; updates add revisions instead of creating unrelated files. Reading revision 2 never marks a newer revision 3 read. The page offers an update without replacing the text underneath you.
