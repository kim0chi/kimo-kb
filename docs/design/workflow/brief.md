# Project brief

Stage: direct implementation, requested by Benedict on 2026-10-14. No Figma
design was selected or approved, and none is required for this build.

Audience: Benedict on laptop and phone. Primary action: resume one useful
learning step or work item, then leave a durable record of what he understood.

Routes: Today, Learn, Work, Library, Studio; secondary Ideas, Journal and
Connections. Existing notebook and coding lab routes remain. Today reads the
real roadmap, notebook schedules, reading state and personal queue.

Visual direction: warm, restrained Kimo palette and IBM Plex fonts, with
shadcn-vue controls and Lucide icons. The dashboard gets a 15rem navigation
rail on desktop; mobile uses a five-destination bottom bar and full-width forms.
The document reader keeps its chapter outline.

No current GitHub, Jira, graph or cloud-AI integration is represented as live.
The SI Windows NUC deployment and private tailnet test are separate work.
Acceptance is a successful build and API/browser checks at phone and desktop
widths, including persistence and empty/error states.
