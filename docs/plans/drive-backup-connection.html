Google setup

  1. Open Google Cloud — create a project. Name it Kimo Backups, then select it in the project picker.
  2. Open Google Drive API and choose Enable for that project.
  3. Open Google Auth platform. If prompted, choose Get started. Use app name Kimo Backups, your email for support/contact and audience External. This is your personal backup client.
  4. In Audience, add your Google account as a test user if the app is in Testing. For a durable background connection, switch publishing status to In production before the final sign-in. Google refresh tokens for external Testing apps normally expire after seven days when Drive access is requested. Publishing the OAuth consent configuration does not publish your archives.
  5. Under Clients, choose Create client → application type Desktop app → name Kimo backup host. Download the JSON credentials.
  6. Save the file as /home/evo-benedict/.config/kimo/google-oauth-client.json, outside any repository. Do not paste its contents in chat.

The uploader requests only drive.file access, for backup files and folders it creates. There is no need to add Gmail or full-Drive access. We will sign in through your local browser, store the resulting refresh token privately on the NUC, then run and verify the actual upload.
