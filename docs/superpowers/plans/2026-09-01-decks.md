# Decks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every doc in kb a second "Present" view — a slide deck derived from
the doc's own structure, ending each section with the flashcards and exercises that
already test it, stored as OpenMAIC DSL documents.

**Architecture:** A pure server-side compiler turns a doc's markdown AST into an
OpenMAIC `Stage` + `Scene[]`: `deck-blocks` (markdown → typed blocks with estimated
heights), `deck-layout` (blocks → positioned elements on a 1000 × 562.5 virtual
canvas), `deck-build` (splitting into scenes, injecting quiz and diagram scenes).
`server/utils/decks.ts` resolves a frozen deck from disk or builds and caches a
derived one, validating with the DSL's own validators before it reaches the client.
A Vue renderer draws the canvas at two sizes — framed in the reading column, and
full-bleed — with `transform: scale()` doing all the responsive work.

**Tech Stack:** Nuxt 4, Vue 3, TypeScript, `@openmaic/dsl`, `unified` +
`remark-parse` + `remark-gfm`, better-sqlite3, `node:test`.

**Spec:** `docs/superpowers/specs/2026-09-01-openmaic-decks-design.md`

## Global Constraints

- **Node 22** — pinned in `mise.toml`. Run everything through `mise exec --`.
- **No network calls, ever.** No LLM, no CDN, no telemetry. The SI corpus is
  company-internal and must not leave the machine.
- **Never write into a notebook's root.** SI_Docs is read-only. Frozen decks go to
  `<library>/decks/`, where `<library>` is `KB_LIBRARY` (default
  `~/Documents/knowledge`).
- **`@openmaic/dsl` pinned to `0.11.0`** (its `DSL_VERSION` is `0.3.0`). It is the
  only new runtime dependency with real weight; it has zero dependencies of its own.
- **Canvas geometry:** `viewportSize` 1000, `viewportRatio` 0.5625 (so the canvas is
  1000 × 562.5 virtual units). Margins: 60 left/right, 48 top, 52 bottom.
- **The DSL's own validators are the boundary check.** Nothing reaches the renderer
  without passing `validateStage` / `validateScene`.
- **Review ids come from the existing `hashId(ns, question)` in `lib/hash.ts`.**
  Never invent a second id scheme — that would orphan every schedule in the DB.
- **Tests are `node:test`**, run with `mise exec -- npm test`. Files go in `tests/`,
  named `<module>.test.ts`, importing with an explicit `.ts` extension (see
  `tests/eraser.test.ts`).
- **Style:** the repo's own voice in code and comments — explain *why*, not *what*.
  No teaching-tone comments.

### Deviation from the spec, and why

The spec's data-flow line says "Nuxt Content AST". This plan parses the markdown
file directly with `unified` + `remark-parse` + `remark-gfm` instead, producing a
standard **mdast**. Three reasons: it is a pure function of a string, so
`deck-blocks` is trivially testable without booting Nuxt; it matches how
`server/utils/flashcards.ts` already reads raw files from disk; and it is the same
AST the repo's existing remark plugins already speak. All three packages are
already in `node_modules` transitively via `@nuxt/content` — this plan makes them
explicit dependencies rather than relying on a transitive one.

/**
 * kb's concrete specialisation of the OpenMAIC scene contract.
 *
 * `Scene` in @openmaic/dsl is generic over its content union so consumers can add
 * widget payloads. kb uses three of the four contract-owned kinds — slide, quiz and
 * interactive (for diagrams) — and no custom actions, so the union is closed here
 * and every other module speaks `KbScene`.
 */
import type {
  Stage,
  Scene,
  SlideContent,
  QuizContent,
  InteractiveContent,
  Slide,
} from '@openmaic/dsl'

/** Virtual canvas width. Element coordinates are in these units, not pixels. */
export const VIEWPORT_SIZE = 1000

/** 16:9 — so the canvas is 1000 x 562.5 virtual units. */
export const VIEWPORT_RATIO = 0.5625

export type KbSceneContent = SlideContent | QuizContent | InteractiveContent

/** Actions are `never`: nothing in kb autoplays, so no scene emits playback verbs. */
export type KbScene = Scene<never, KbSceneContent>

export interface Deck {
  stage: Stage
  scenes: KbScene[]
}

/** An empty canvas with kb's geometry. Callers fill `elements`. */
export function blankSlide(id: string): Slide {
  return {
    id,
    viewportSize: VIEWPORT_SIZE,
    viewportRatio: VIEWPORT_RATIO,
    theme: {
      themeColors: ['var(--accent)', 'var(--role-server)'],
      fontColor: 'var(--text)',
      fontName: 'IBM Plex Sans',
      backgroundColor: 'var(--panel)',
    },
    elements: [],
  }
}

/**
 * The minimum viable deck: a Stage plus a single title scene. Used as the floor for
 * a doc that yields no usable blocks, so "no content" degrades to a near-empty deck
 * rather than an error the reader has to handle.
 */
export function emptyDeck(docPath: string, title: string): Deck {
  const stage: Stage = {
    id: docPath,
    name: title,
    // Fixed rather than Date.now(): a deck is a pure function of its doc, and a
    // moving timestamp would change the payload on every rebuild and defeat the
    // content-hash cache.
    createdAt: 0,
    updatedAt: 0,
  }
  return {
    stage,
    scenes: [
      {
        id: `${docPath}#0`,
        stageId: stage.id,
        title,
        order: 0,
        type: 'slide',
        content: { type: 'slide', canvas: blankSlide(`${docPath}#0`) },
      },
    ],
  }
}
```

/**
 * Canvas geometry and height estimation.
 *
 * The builder runs on the server, where there is no layout engine to measure text
 * against. Heights are therefore ESTIMATED from character counts and font metrics.
 * The estimate is deliberately slightly generous: a scene that breaks one block
 * early reads fine, a scene that overflows does not.
 *
 * Every constant here is a tuning knob. If decks come out too sparse or too dense,
 * this is the only file to change.
 */
import { VIEWPORT_SIZE, VIEWPORT_RATIO } from './deck-types'

const MARGIN_X = 60
const MARGIN_TOP = 48
const MARGIN_BOTTOM = 52

/** Height of the title band at the top of a content scene. */
const TITLE_BAND = 82

export const CANVAS = {
  width: VIEWPORT_SIZE,
  height: VIEWPORT_SIZE * VIEWPORT_RATIO,
  marginX: MARGIN_X,
  contentLeft: MARGIN_X,
  contentWidth: VIEWPORT_SIZE - MARGIN_X * 2,
  contentTop: MARGIN_TOP + TITLE_BAND,
  get contentHeight(): number {
    return VIEWPORT_SIZE * VIEWPORT_RATIO - (MARGIN_TOP + TITLE_BAND) - MARGIN_BOTTOM
  },
  titleTop: MARGIN_TOP,
  titleBand: TITLE_BAND,
} as const

export interface FontSpec {
  size: number
  /** Multiplier on `size` to get a line box. */
  lineHeight: number
  /** Space after the block. */
  spaceAfter: number
}

/**
 * Font sizes in canvas units. Chosen so body text on a full-bleed 1080p screen
 * lands near 19 CSS px, which is close to kb's reading size.
 */
export const FONT = {
  title: { size: 40, lineHeight: 1.2, spaceAfter: 10 },
  subtitle: { size: 22, lineHeight: 1.45, spaceAfter: 16 },
  itemTitle: { size: 26, lineHeight: 1.3, spaceAfter: 10 },
  content: { size: 19, lineHeight: 1.5, spaceAfter: 14 },
  item: { size: 19, lineHeight: 1.5, spaceAfter: 8 },
  notes: { size: 15, lineHeight: 1.5, spaceAfter: 10 },
  code: { size: 15, lineHeight: 1.55, spaceAfter: 14 },
} as const satisfies Record<string, FontSpec>

/**
 * Mean glyph advance as a fraction of font size, for IBM Plex Sans. Measured off a
 * prose sample; wrong by a few percent either way, which the generous line rounding
 * absorbs.
 */
const GLYPH_RATIO = 0.52

/** Padding inside a code block, top plus bottom. */
const CODE_PADDING = 26

const TABLE_ROW = 32
const TABLE_HEADER = 36
const TABLE_SPACE_AFTER = 14

/** Estimated height of a run of text laid out in the content column. */
export function textHeight(text: string, font: FontSpec, width = CANVAS.contentWidth): number {
  const perLine = Math.max(1, Math.floor(width / (font.size * GLYPH_RATIO)))
  const lines = Math.max(1, Math.ceil(text.length / perLine))
  return lines * font.size * font.lineHeight + font.spaceAfter
}

/** Code does not wrap, so only the newline count matters. */
export function codeHeight(value: string): number {
  const lines = value.split('\n').length
  return lines * FONT.code.size * FONT.code.lineHeight + CODE_PADDING + FONT.code.spaceAfter
}

export function tableHeight(rowCount: number): number {
  return TABLE_HEADER + rowCount * TABLE_ROW + TABLE_SPACE_AFTER
}
```

```ts
/**
 * markdown -> a flat list of typed blocks.
 *
 * This is the only place that touches mdast. Everything downstream works on `Block`,
 * which carries both `html` (what the renderer draws) and `text` (what the height
 * estimator counts), so no later stage has to re-derive one from the other.
 *
 * Fence handling mirrors the rest of the app on purpose: ```mermaid and ```eraser
 * are diagrams (see lib/remark-mermaid.ts, lib/remark-eraser.ts) and ```flashcard is
 * a review card (see server/utils/flashcards.ts), not code to display.
 */
import { unified } from 'unified'
import remarkParse from 'remark-parse'
import remarkGfm from 'remark-gfm'
import { FONT, textHeight, codeHeight, tableHeight, type FontSpec } from './deck-geometry'

export interface Inline {
  html: string
  text: string
}

export type Block =
  | ({ kind: 'heading'; depth: 2 | 3 } & Inline)
  | ({ kind: 'paragraph' } & Inline)
  | { kind: 'list'; ordered: boolean; items: Inline[] }
  | { kind: 'code'; lang: string; value: string }
  | { kind: 'table'; header: string[]; rows: string[][] }
  | ({ kind: 'quote' } & Inline)
  | { kind: 'diagram'; lang: 'mermaid' | 'eraser'; value: string }
  | { kind: 'flashcard'; front: string; back: string }
  | { kind: 'image'; url: string; alt: string }

interface MdNode {
  type: string
  depth?: number
  lang?: string | null
  value?: string
  url?: string
  alt?: string
  ordered?: boolean
  children?: MdNode[]
}

const escapeHtml = (s: string): string =>
  s.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;')

/** Inline mdast -> a small, safe subset of HTML. Anything unknown degrades to text. */
function inline(nodes: MdNode[] = []): Inline {
  let html = ''
  let text = ''
  for (const n of nodes) {
    switch (n.type) {
      case 'text':
        html += escapeHtml(n.value ?? '')
        text += n.value ?? ''
        break
      case 'inlineCode':
        html += `<code>${escapeHtml(n.value ?? '')}</code>`
        text += n.value ?? ''
        break
      case 'strong': {
        const c = inline(n.children)
        html += `<strong>${c.html}</strong>`
        text += c.text
        break
      }
      case 'emphasis': {
        const c = inline(n.children)
        html += `<em>${c.html}</em>`
        text += c.text
        break
      }
      case 'delete': {
        const c = inline(n.children)
        html += `<s>${c.html}</s>`
        text += c.text
        break
      }
      case 'link': {
        const c = inline(n.children)
        // Rendered as plain emphasis: a deck is a linear presentation, and a link
        // that navigates away mid-deck loses your place.
        html += `<span class="lnk">${c.html}</span>`
        text += c.text
        break
      }
      case 'break':
        html += '<br>'
        text += ' '
        break
      default: {
        const c = inline(n.children)
        html += c.html
        text += c.text
      }
    }
  }
  return { html, text }
}

/** Flatten a table cell to plain text — cells are short and get no inline markup. */
const cellText = (n: MdNode): string => inline(n.children).text.trim()

function flashcardBlock(value: string): Block | null {
  const sep = value.search(/^\s*---\s*$/m)
  if (sep === -1) return null
  const front = value.slice(0, sep).trim()
  const back = value.slice(value.indexOf('\n', sep) + 1).trim()
  if (!front || !back) return null
  return { kind: 'flashcard', front, back }
}

function codeLikeBlock(node: MdNode): Block | null {
  const lang = (node.lang ?? '').toLowerCase()
  const value = (node.value ?? '').replace(/\s+$/, '')
  if (lang === 'mermaid' || lang === 'eraser') return { kind: 'diagram', lang, value }
  if (lang === 'flashcard') return flashcardBlock(value)
  if (!value) return null
  return { kind: 'code', lang, value }
}

function convert(node: MdNode, out: Block[]): void {
  switch (node.type) {
    case 'heading': {
      const depth = node.depth ?? 1
      // The H1 is the deck title, pulled out by parseBlocks. H4+ is rare in this
      // corpus and reads fine as an itemTitle.
      if (depth <= 1) return
      out.push({ kind: 'heading', depth: depth === 2 ? 2 : 3, ...inline(node.children) })
      return
    }
    case 'paragraph': {
      const only = node.children?.length === 1 ? node.children[0] : null
      if (only?.type === 'image') {
        out.push({ kind: 'image', url: only.url ?? '', alt: only.alt ?? '' })
        return
      }
      const c = inline(node.children)
      if (c.text.trim()) out.push({ kind: 'paragraph', ...c })
      return
    }
    case 'list': {
      const items = (node.children ?? []).map((li) => {
        // A list item wraps its content in a paragraph; unwrap so the item reads as
        // one line rather than a nested block.
        const kids = li.children?.length === 1 && li.children[0].type === 'paragraph'
          ? li.children[0].children
          : li.children
        return inline(kids)
      })
      if (items.length) out.push({ kind: 'list', ordered: Boolean(node.ordered), items })
      return
    }
    case 'code': {
      const b = codeLikeBlock(node)
      if (b) out.push(b)
      return
    }
    case 'table': {
      const rows = (node.children ?? []).map((tr) => (tr.children ?? []).map(cellText))
      if (!rows.length) return
      out.push({ kind: 'table', header: rows[0], rows: rows.slice(1) })
      return
    }
    case 'blockquote': {
      const c = inline(node.children)
      if (c.text.trim()) out.push({ kind: 'quote', ...c })
      return
    }
    case 'thematicBreak':
      return
    default:
      for (const child of node.children ?? []) convert(child, out)
  }
}

/** Estimated height of a block in canvas units. Drives the splitting decision. */
export function blockHeight(b: Block): number {
  switch (b.kind) {
    case 'heading':
      return textHeight(b.text, b.depth === 2 ? FONT.itemTitle : FONT.itemTitle)
    case 'paragraph':
      return textHeight(b.text, FONT.content)
    case 'quote':
      // The callout rule and its inset add to a plain paragraph.
      return textHeight(b.text, FONT.content, FONT.content.size * 40) + 16
    case 'list':
      return b.items.reduce((sum, i) => sum + textHeight(i.text, FONT.item), 0)
    case 'code':
      return codeHeight(b.value)
    case 'table':
      return tableHeight(b.rows.length)
    case 'image':
      return 240
    case 'diagram':
    case 'flashcard':
      // Both leave the slide flow entirely — they become scenes of their own — so
      // they never consume a slide's budget.
      return 0
  }
}

const FRONTMATTER = /^---\r?\n[\s\S]*?\r?\n---\r?\n?/

export function parseBlocks(markdown: string): { title: string; blocks: Block[] } {
  const body = markdown.replace(FRONTMATTER, '')
  const tree = unified().use(remarkParse).use(remarkGfm).parse(body) as unknown as MdNode

  let title = ''
  const blocks: Block[] = []
  for (const node of tree.children ?? []) {
    if (!title && node.type === 'heading' && node.depth === 1) {
      title = inline(node.children).text.trim()
      continue
    }
    convert(node, blocks)
  }
  return { title, blocks }
}

export type { FontSpec }

```ts
/**
 * Blocks -> positioned elements on one canvas.
 *
 * Single-column flow: a title band at the top, then blocks stacked down the content
 * column at their estimated heights. Splitting has already happened by the time this
 * runs (see deck-build) — this function lays out exactly what it is given and does
 * not decide what fits.
 *
 * Elements are emitted minimally and passed through the DSL's `normalizeElement`,
 * which fills the contract's required defaults. That keeps this file about geometry
 * and leaves the defaults to the package that owns them.
 */
import { normalizeElement, type PPTElement, type Slide } from '@openmaic/dsl'
import { CANVAS, FONT } from './deck-geometry'
import { blankSlide } from './deck-types'
import { blockHeight, type Block } from './deck-blocks'

/** Accent rule under the scene title. */
const RULE_WIDTH = 52
const RULE_HEIGHT = 4

const QUOTE_INSET = 28

function textEl(
  id: string,
  top: number,
  height: number,
  html: string,
  textType: 'title' | 'subtitle' | 'content' | 'item' | 'itemTitle' | 'notes',
  left = CANVAS.contentLeft,
  width = CANVAS.contentWidth,
): PPTElement {
  const font = FONT[textType]
  return normalizeElement({
    id,
    type: 'text',
    left,
    top,
    width,
    height,
    rotate: 0,
    content: html,
    textType,
    lineHeight: font.lineHeight,
    // Emitted for imported-PPTX compatibility; kb's renderer styles by textType and
    // ignores both, so a deck follows the light/dark toggle.
    defaultFontName: 'IBM Plex Sans',
    defaultColor: 'var(--text)',
  })
}

export function layoutScene(id: string, title: string, blocks: Block[]): Slide {
  const slide = blankSlide(id)
  const els: PPTElement[] = []
  let n = 0
  const nextId = () => `${id}-e${n++}`

  if (title) {
    els.push(
      textEl(nextId(), CANVAS.titleTop, FONT.title.size * FONT.title.lineHeight, title, 'title'),
    )
    els.push(
      normalizeElement({
        id: nextId(),
        type: 'shape',
        left: CANVAS.contentLeft,
        top: CANVAS.titleTop + FONT.title.size * FONT.title.lineHeight + 8,
        width: RULE_WIDTH,
        height: RULE_HEIGHT,
        rotate: 0,
        viewBox: [200, 200],
        path: 'M 0 0 L 200 0 L 200 200 L 0 200 Z',
        fill: 'var(--accent)',
      }),
    )
  }

  let y = CANVAS.contentTop
  for (const block of blocks) {
    const h = blockHeight(block)
    switch (block.kind) {
      case 'heading':
        els.push(textEl(nextId(), y, h, block.html, 'itemTitle'))
        break
      case 'paragraph':
        els.push(textEl(nextId(), y, h, block.html, 'content'))
        break
      case 'list': {
        let iy = y
        for (const item of block.items) {
          const ih = blockHeight({ kind: 'list', ordered: block.ordered, items: [item] })
          const bullet = block.ordered ? `${block.items.indexOf(item) + 1}.` : '&bull;'
          els.push(
            textEl(
              nextId(),
              iy,
              ih,
              `<span class="bul">${bullet}</span> ${item.html}`,
              'item',
            ),
          )
          iy += ih
        }
        break
      }
      case 'quote':
        els.push(
          normalizeElement({
            id: nextId(),
            type: 'shape',
            left: CANVAS.contentLeft,
            top: y,
            width: RULE_HEIGHT,
            height: h,
            rotate: 0,
            viewBox: [200, 200],
            path: 'M 0 0 L 200 0 L 200 200 L 0 200 Z',
            fill: 'var(--accent)',
          }),
        )
        els.push(
          textEl(
            nextId(),
            y,
            h,
            block.html,
            'content',
            CANVAS.contentLeft + QUOTE_INSET,
            CANVAS.contentWidth - QUOTE_INSET,
          ),
        )
        break
      case 'code':
        els.push(
          normalizeElement({
            id: nextId(),
            type: 'code',
            left: CANVAS.contentLeft,
            top: y,
            width: CANVAS.contentWidth,
            height: h,
            rotate: 0,
            language: block.lang,
            lines: block.value.split('\n').map((text) => ({ text })),
            fontSize: FONT.code.size,
            showLineNumbers: false,
          }),
        )
        break
      case 'table':
        els.push(
          normalizeElement({
            id: nextId(),
            type: 'table',
            left: CANVAS.contentLeft,
            top: y,
            width: CANVAS.contentWidth,
            height: h,
            rotate: 0,
            colWidths: block.header.map(() => 1 / Math.max(1, block.header.length)),
            data: [
              block.header.map((text) => ({ id: `${nextId()}h`, colspan: 1, rowspan: 1, text })),
              ...block.rows.map((row) =>
                row.map((text) => ({ id: `${nextId()}c`, colspan: 1, rowspan: 1, text })),
              ),
            ],
          }),
        )
        break
      case 'image':
        els.push(
          normalizeElement({
            id: nextId(),
            type: 'image',
            left: CANVAS.contentLeft,
            top: y,
            width: CANVAS.contentWidth,
            height: h,
            rotate: 0,
            src: block.url,
            fixedRatio: true,
            name: block.alt,
          }),
        )
        break
      case 'diagram':
      case 'flashcard':
        // Both became scenes of their own upstream; nothing to place.
        continue
    }
    y += h
  }

  slide.elements = els
  return slide
}

```ts
/**
 * Doc -> deck. Owns the splitting strategy and nothing else.
 *
 * One scene per H2 section. Blocks accumulate onto the current scene until the
 * height budget is spent, then a continuation scene opens carrying the same title.
 * A code block or table that will not fit in the room that is left starts its own
 * scene rather than being cut in half.
 *
 * Two block kinds leave the slide flow entirely: diagrams become interactive scenes
 * (the DSL's own slot for a rendered widget), and flashcards become quiz scenes
 * placed at the end of the section that authored them.
 *
 * Pure: no I/O, no clock, no randomness. A deck is a function of its doc, which is
 * what lets `server/utils/decks.ts` cache one against a hash of the source.
 */
import { normalizeScene, normalizeStage, type Stage } from '@openmaic/dsl'
import { CANVAS } from './deck-geometry'
import { parseBlocks, blockHeight, type Block } from './deck-blocks'
import { layoutScene } from './deck-layout'
import { emptyDeck, type Deck, type KbScene } from './deck-types'

/** A reviewable item to show as a quiz scene. Ids come from the caller — see hash.ts. */
export interface DeckQuestion {
  id: string
  prompt: string
  /** null → no model answer; the reader checks against the doc instead. */
  answer: string | null
  kind: 'flashcard' | 'exercise'
}

export interface DeckInput {
  docPath: string
  markdown: string
  /** Cards and exercises already resolved for this doc. */
  questions: DeckQuestion[]
}

/** Blocks that never occupy slide space. */
const isAside = (b: Block): boolean => b.kind === 'diagram' || b.kind === 'flashcard'

/** A block that reads badly when split off from its lead-in, so it gets its own scene. */
const isIndivisible = (b: Block): boolean => b.kind === 'code' || b.kind === 'table'

export function buildDeck({ docPath, markdown, questions }: DeckInput): Deck {
  const { title, blocks } = parseBlocks(markdown)
  if (!blocks.length) return emptyDeck(docPath, title)

  const stage: Stage = {
    id: docPath,
    name: title || docPath,
    createdAt: 0,
    updatedAt: 0,
  }

  const byPrompt = new Map(questions.map((q) => [q.prompt.trim(), q]))
  const used = new Set<string>()
  const scenes: KbScene[] = []

  const sceneId = () => `${docPath}#${scenes.length}`

  const pushSlide = (sceneTitle: string, group: Block[]): void => {
    const id = sceneId()
    scenes.push({
      id,
      stageId: stage.id,
      title: sceneTitle,
      order: scenes.length,
      type: 'slide',
      content: { type: 'slide', canvas: layoutScene(id, sceneTitle, group) },
    })
  }

  const pushDiagram = (sceneTitle: string, b: Extract<Block, { kind: 'diagram' }>): void => {
    const id = sceneId()
    scenes.push({
      id,
      stageId: stage.id,
      title: sceneTitle,
      order: scenes.length,
      type: 'interactive',
      content: {
        type: 'interactive',
        widgetType: 'diagram',
        // The source, not a rendering: the SVG is produced client-side at view time
        // (and inlined here only when a deck is frozen). `lang` tells the renderer
        // which of the two dialects it is.
        html: `<pre data-diagram="${b.lang}">${b.value
          .replace(/&/g, '&amp;')
          .replace(/</g, '&lt;')
          .replace(/>/g, '&gt;')}</pre>`,
      },
    })
  }

  const pushQuiz = (sceneTitle: string, items: DeckQuestion[]): void => {
    if (!items.length) return
    scenes.push({
      id: sceneId(),
      stageId: stage.id,
      title: sceneTitle,
      order: scenes.length,
      type: 'quiz',
      content: {
        type: 'quiz',
        questions: items.map((q) => ({
          id: q.id,
          type: 'short_answer' as const,
          question: q.prompt,
          answer: q.answer ? [q.answer] : [],
          analysis: q.answer ?? '',
          hasAnswer: Boolean(q.answer),
        })),
      },
    })
  }

  // Group blocks into sections: everything before the first H2 is the title section.
  interface Section {
    title: string
    blocks: Block[]
  }
  const sections: Section[] = [{ title, blocks: [] }]
  for (const b of blocks) {
    if (b.kind === 'heading' && b.depth === 2) sections.push({ title: b.text, blocks: [] })
    else sections[sections.length - 1].blocks.push(b)
  }

  for (const section of sections) {
    const pending: DeckQuestion[] = []
    let group: Block[] = []
    let used_h = 0

    const flush = (): void => {
      if (group.length) {
        pushSlide(section.title, group)
        group = []
        used_h = 0
      }
    }

    for (const b of section.blocks) {
      if (b.kind === 'flashcard') {
        const q = byPrompt.get(b.front.trim())
        if (q && !used.has(q.id)) {
          used.add(q.id)
          pending.push(q)
        }
        continue
      }
      if (b.kind === 'diagram') {
        flush()
        pushDiagram(section.title, b)
        continue
      }

      const h = blockHeight(b)
      const fits = used_h + h <= CANVAS.contentHeight

      if (!fits && group.length) flush()
      // An indivisible block that is on its own and still too tall goes on a scene
      // by itself and overflows visibly, rather than silently losing content.
      if (!fits && !group.length && isIndivisible(b)) {
        pushSlide(section.title, [b])
        continue
      }

      group.push(b)
      used_h += h
    }

    flush()
    pushQuiz(section.title, pending)
  }

  // Anything supplied but never matched to an inline fence — derived glossary cards
  // and roadmap exercises — becomes one quiz scene at the end.
  const leftovers = questions.filter((q) => !used.has(q.id))
  if (leftovers.length) pushQuiz(title || 'Check yourself', leftovers)

  if (!scenes.length) return emptyDeck(docPath, title)

  return {
    stage: normalizeStage(stage),
    scenes: scenes.map((s) => normalizeScene(s) as KbScene),
  }
}

export { isAside }
```

/**
 * Which reviewable items belong to a doc.
 *
 * Flashcards know their source file, so they map by path. Exercises are declarative:
 * an authored one lists `refs`, and a roadmap-derived one inherits the step's `learn`
 * paths (see server/utils/exercises.ts), so both map by reference.
 *
 * Ids are passed straight through. They come from `hashId` and are the same ids
 * /review and /exercises schedule against — grading in a deck must write the same row.
 */
import { relative, sep } from 'node:path'
import type { Notebook } from '../../lib/notebooks'
import { treePrefix } from '../../lib/notebooks'
import type { Card } from './flashcards'
import type { Exercise } from './exercises'
import type { DeckQuestion } from '../../lib/deck-build'

/** Same rule as `treeSlug`, applied per path segment. */
const slugSegment = (s: string): string =>
  s.toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-+|-+$/g, '')

/**
 * Absolute file path -> the namespaced content path Nuxt Content serves it at.
 * `/r/SI_Docs/sections/06-data-model.md` -> `/si/si-docs/sections/06-data-model`.
 */
export function contentPathFor(nb: Notebook, tree: string, absFile: string): string {
  const base = tree === '.' ? nb.root : `${nb.root}/${tree}`
  const rel = relative(base, absFile).split(sep)
  const file = rel.pop() ?? ''
  const stem = file.replace(/\.md$/i, '')
  const segments = [...rel, ...(stem === 'index' ? [] : [stem])].map(slugSegment).filter(Boolean)
  return [treePrefix(nb, tree), ...segments].join('/')
}

/**
 * Cards first, then exercises: recall before explanation, the same order the two
 * review surfaces sit in.
 */
export function questionsForDoc(
  cards: Card[],
  exercises: Exercise[],
  docPath: string,
): DeckQuestion[] {
  const out: DeckQuestion[] = []
  for (const c of cards) {
    if (c.docPath === docPath) {
      out.push({ id: c.id, prompt: c.front, answer: c.back, kind: 'flashcard' })
    }
  }
  for (const e of exercises) {
    if (e.refs.includes(docPath)) {
      out.push({ id: e.id, prompt: e.prompt, answer: e.answer, kind: 'exercise' })
    }
  }
  return out
}

/** A cached deck, only if it was built from the source we still have. */
export function cachedDeck(docPath: string, sourceHash: string): unknown | null {
  const row = useDb()
    .prepare('SELECT payload FROM decks WHERE doc_path = ? AND source_hash = ?')
    .get(docPath, sourceHash) as { payload: string } | undefined
  if (!row) return null
  try {
    return JSON.parse(row.payload)
  } catch {
    // A corrupt row is a cache miss, never an error: the deck rebuilds.
    return null
  }
}

export function putDeck(docPath: string, sourceHash: string, deck: unknown, now: string): void {
  useDb()
    .prepare(
      `INSERT INTO decks (doc_path, source_hash, payload, updated_at) VALUES (?, ?, ?, ?)
       ON CONFLICT(doc_path) DO UPDATE SET source_hash = excluded.source_hash,
         payload = excluded.payload, updated_at = excluded.updated_at`,
    )
    .run(docPath, sourceHash, JSON.stringify(deck), now)
}

```ts
/**
 * Resolve a deck for a doc: frozen file, cache, or build.
 *
 * The house pattern — derived by default, authored wins. A frozen deck under
 * <library>/decks/ is used as-is; otherwise the deck is built from the doc and
 * cached against a hash of its source, so editing the doc invalidates it.
 *
 * Nothing is ever written into a notebook's root. The SI corpus is read-only.
 */
import { readFileSync, existsSync, readdirSync, statSync } from 'node:fs'
import { join } from 'node:path'
import { createHash } from 'node:crypto'
import { validateStage, validateScene } from '@openmaic/dsl'
import type { Notebook } from '../../lib/notebooks'
import { buildDeck } from '../../lib/deck-build'
import type { Deck } from '../../lib/deck-types'
import { loadCards } from './flashcards'
import { loadExerciseFiles, roadmapExercises, mergeExercises } from './exercises'
import { loadRoadmap } from './roadmap'
import { contentPathFor, questionsForDoc } from './deck-questions'
import { cachedDeck, putDeck } from './db'

/**
 * Everything resolving a deck needs from the outside world. Passed in rather than
 * read from runtime config, because freeze-deck.mjs runs with no Nitro event.
 */
export interface DeckContext {
  libraryDir: string
  notebooks: Notebook[]
}

/**
 * Where a frozen deck lives. Mirrors the content path with the notebook id kept as
 * the first segment: /cs/complexity/big-o -> <library>/decks/cs/complexity/big-o.stage.json
 */
export function frozenDeckPath(libDir: string, docPath: string): string {
  const clean = docPath.replace(/^\/+/, '').replace(/\.\./g, '')
  return join(libDir, 'decks', `${clean}.stage.json`)
}

/** Walk a notebook's trees for the file that serves `docPath`. */
function sourceFileFor(nb: Notebook, docPath: string): { tree: string; file: string } | null {
  const found: { tree: string; file: string }[] = []
  const walk = (dir: string, tree: string): void => {
    if (!existsSync(dir)) return
    for (const entry of readdirSync(dir)) {
      const full = join(dir, entry)
      if (statSync(full).isDirectory()) walk(full, tree)
      else if (entry.endsWith('.md')) found.push({ tree, file: full })
    }
  }
  for (const tree of nb.trees) walk(tree === '.' ? nb.root : join(nb.root, tree), tree)
  return found.find((f) => contentPathFor(nb, f.tree, f.file) === docPath) ?? null
}

export interface ResolvedDeck {
  deck: Deck
  /** 'frozen' when it came from disk — surfaced so the UI can say so. */
  origin: 'frozen' | 'derived'
}

export function resolveDeck(docPath: string, ctx: DeckContext): ResolvedDeck | null {
  const { libraryDir: libDir, notebooks } = ctx

  const frozen = frozenDeckPath(libDir, docPath)
  if (existsSync(frozen)) {
    try {
      const deck = JSON.parse(readFileSync(frozen, 'utf8')) as Deck
      const bad = validateDeck(deck)
      if (!bad.length) return { deck, origin: 'frozen' }
      // A bad hand-edit must not take the doc down — warn and fall through to derived.
      console.warn(`[decks] ignoring invalid frozen deck ${frozen}:`, bad.join('; '))
    } catch (e) {
      console.warn(`[decks] could not read frozen deck ${frozen}:`, (e as Error).message)
    }
  }

  const nbId = docPath.split('/')[1]
  const nb = notebooks.find((n) => n.id === nbId)
  if (!nb) return null

  const src = sourceFileFor(nb, docPath)
  if (!src) return null

  let markdown: string
  try {
    markdown = readFileSync(src.file, 'utf8')
  } catch {
    return null
  }

  const hash = createHash('sha256').update(markdown).digest('hex').slice(0, 16)
  const hit = cachedDeck(docPath, hash) as Deck | null
  if (hit) return { deck: hit, origin: 'derived' }

  // Composed exactly as server/api/exercises.get.ts composes it: authored YAML
  // first, then whatever the roadmap's objectives imply.
  const exercises = mergeExercises(
    loadExerciseFiles(libDir, nb.id).exercises,
    roadmapExercises(loadRoadmap(libDir).roadmap, nb.id),
  )
  const cards = loadCards(nb)
  const deck = buildDeck({
    docPath,
    markdown,
    questions: questionsForDoc(cards, exercises, docPath),
  })

  const bad = validateDeck(deck)
  if (bad.length) {
    console.warn(`[decks] built an invalid deck for ${docPath}:`, bad.join('; '))
    return null
  }

  putDeck(docPath, hash, deck, new Date().toISOString())
  return { deck, origin: 'derived' }
}

/** Every validation failure, as `path: message` strings. Empty means valid. */
function validateDeck(deck: Deck): string[] {
  const out: string[] = []
  const stage = validateStage(deck.stage)
  if (!stage.valid) out.push(...stage.errors.map((e) => `stage ${e.path}: ${e.message}`))
  for (const scene of deck.scenes ?? []) {
    const r = validateScene(scene)
    if (!r.valid) out.push(...r.errors.map((e) => `${scene.id} ${e.path}: ${e.message}`))
  }
  return out
}
```

// as one component rather than two routes is what keeps paging, keyboard handling
// and the pip strip from being written twice.
import type { KbScene } from '~~/lib/deck-types'

const props = defineProps<{ path: string }>()

const { data, pending, error } = await useFetch(() => `/api/deck?path=${props.path}`, {
  key: () => `deck:${props.path}`,
})

const scenes = computed<KbScene[]>(() => (data.value?.deck?.scenes ?? []) as KbScene[])
const i = ref(0)
const full = ref(false)

const scene = computed(() => scenes.value[i.value] ?? null)
const notes = computed(() => {
  const s = scene.value
  return s?.type === 'slide' ? (s.content.canvas.script ?? '') : ''
})

// Which questions are flashcards and which are exercises, so the quiz scene can label
// its grade buttons correctly. Derived once from the deck.
const kinds = computed<Record<string, 'flashcard' | 'exercise'>>(() => {
  const out: Record<string, 'flashcard' | 'exercise'> = {}
  for (const s of scenes.value) {
    if (s.type !== 'quiz') continue
    for (const q of s.content.questions) out[q.id] = q.hasAnswer ? 'flashcard' : 'exercise'
  }
  return out
})

const go = (n: number): void => {
  i.value = Math.min(Math.max(0, i.value + n), Math.max(0, scenes.value.length - 1))
}

function onKey(e: KeyboardEvent): void {
  // Never steal keys from the answer box in a quiz scene.
  const t = e.target as HTMLElement | null
  if (t && (t.tagName === 'TEXTAREA' || t.tagName === 'INPUT')) return
  if (e.key === 'ArrowRight') go(1)
  else if (e.key === 'ArrowLeft') go(-1)
  else if (e.key === 'Escape' && full.value) full.value = false
}

onMounted(() => window.addEventListener('keydown', onKey))
onBeforeUnmount(() => window.removeEventListener('keydown', onKey))
watch(full, (on) => {
  document.body.style.overflow = on ? 'hidden' : ''
})
onBeforeUnmount(() => {
  document.body.style.overflow = ''
})
</script>

- [ ] **Step 1: Write the corpus test**

Create `tests/deck-corpus.test.ts`:

```ts
import { test } from 'node:test'
import assert from 'node:assert/strict'
import { readFileSync, readdirSync, statSync, existsSync } from 'node:fs'
import { join } from 'node:path'
import { validateStage, validateScene } from '@openmaic/dsl'
import { buildDeck } from '../lib/deck-build.ts'

// Every doc in the library must compile to a valid deck. This is the test that keeps
// the portability claim honest: if a DSL upgrade tightens the schema, or a doc uses
// markdown the builder mishandles, it fails here rather than in the browser.

const LIB = process.env.KB_LIBRARY || join(process.env.HOME ?? '', 'Documents', 'knowledge')

function allDocs(dir: string, out: string[] = []): string[] {
  if (!existsSync(dir)) return out
  for (const entry of readdirSync(dir)) {
    if (entry === 'decks' || entry === 'node_modules' || entry.startsWith('.')) continue
    const full = join(dir, entry)
    if (statSync(full).isDirectory()) allDocs(full, out)
    else if (entry.endsWith('.md')) out.push(full)
  }
  return out
}

test('every doc in the library builds a deck that passes the DSL validators', (t) => {
  const docs = allDocs(LIB)
  if (!docs.length) return t.skip(`no library at ${LIB}`)

  const failures: string[] = []
  for (const file of docs) {
    const deck = buildDeck({
      docPath: `/probe${file.replace(LIB, '')}`,
      markdown: readFileSync(file, 'utf8'),
      questions: [],
    })
    const stage = validateStage(deck.stage)
    if (!stage.valid) failures.push(`${file} stage: ${JSON.stringify(stage.errors)}`)
    for (const scene of deck.scenes) {
      const r = validateScene(scene)
      if (!r.valid) failures.push(`${file} ${scene.id}: ${JSON.stringify(r.errors)}`)
    }
  }
  assert.deepEqual(failures, [], failures.join('\n'))
})

test('no deck is absurdly long or empty', (t) => {
  const docs = allDocs(LIB)
  if (!docs.length) return t.skip(`no library at ${LIB}`)

  for (const file of docs) {
    const md = readFileSync(file, 'utf8')
    const deck = buildDeck({ docPath: '/probe', markdown: md, questions: [] })
    assert.ok(deck.scenes.length >= 1, `${file} produced no scenes`)
    // A doc's deck should not need more scenes than it has lines — that would mean
    // the height budget has collapsed.
    assert.ok(
      deck.scenes.length < Math.max(20, md.split('\n').length),
      `${file} produced ${deck.scenes.length} scenes — check the height budget`,
    )
  }
})
```

```markdown
- [x] **Phase 21 — Decks**: any doc has a second **Present** view — a slide deck
      derived from its own structure, no LLM and no network. One scene per `##`
      section, splitting onto a continuation slide when a section outgrows the
      canvas, with tables and code blocks given room of their own. Mermaid and
      eraser fences become diagram scenes; the doc's flashcards and exercises become
      **quiz scenes** at the end of the section that authored them, grading onto the
      **same SM-2 schedule** as `/review` and `/exercises` — same ids, same rows, no
      second history.

      Decks are documents in the **OpenMAIC DSL** (`@openmaic/dsl`, pinned to
      `0.11.0`) rather than a kb-only shape, so they stay portable — PPTX export and
      the rest of the OpenMAIC tooling remain open. We take the contract package
      only: its renderer and editor are React, and its generation pipeline needs an
      LLM. The canvas is resolution-independent (`viewportSize` 1000, 16:9), so one
      `transform: scale()` serves the framed view, the full-bleed view and a phone.

      Derived by default, authored wins — the same rule flashcards and exercises
      follow. A deck is built on demand and cached in SQLite against a hash of the
      doc, so it can never drift; `npm run freeze-deck -- /<notebook>/<…>` writes one
      to `<library>/decks/` for hand-editing, and a frozen deck overrides the derived
      one. Nothing is written into a notebook's root — SI_Docs stays read-only.

      Heights are **estimated**, not measured: the builder runs on the server, where
      there is no layout engine, so it sizes blocks from character counts and font
      metrics. Every constant lives in `lib/deck-geometry.ts`; that is the only file
      to touch if decks come out too dense or too sparse.
```
